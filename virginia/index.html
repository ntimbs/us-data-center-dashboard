Statistics

How the county comparisons work

Pearson r

Correlation between the outcome and comparison variable in the same counties with both values. It ranges from −1 to 1 and does not adjust for spatial dependence.

Outcome Moran’s I

Global clustering of the selected outcome using row-standardized queen neighbors. Positive values indicate similar values tend to be adjacent. No permutation p-value is reported.

Spatial-lag r

Correlation between each county’s outcome and the average comparison value among adjacent counties. It is descriptive and is not a causal estimator.

Bivariate map

Classifies counties as high or low relative to the Virginia mean for both selected variables.

Complete pairs

Counties with numeric values for both selected variables. Unknown values are excluded; valid zeros remain in the calculation.

Independent cities

Virginia independent cities are county equivalents. Small city polygons can be difficult to select; facility points and the detail panel help reveal them.
